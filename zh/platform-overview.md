# 平台概览

## 平台定位

SPLY 是面向 BNB Smart Chain 的模板化发射平台。它覆盖的不是单一动作，而是完整发射链路中的多个关键环节：

- 项目创建
- 模板选择
- 募资进行
- 资金托管
- 开盘建池
- 交易进入公开市场
- 源码验证
- 项目与代币展示
- 开发者模板审核与上架

因此，SPLY 更接近“发射基础设施 + 发射产品层”的结合体，而不是纯合约库，也不是单页应用。

## 产品表面

从前台到后台，SPLY 当前有这些主要界面：

## 首页

首页负责展示平台活跃状态和公开项目入口，包括：

- 总项目数
- 募资统计
- 热门项目
- 搜索与筛选
- 最新项目列表

## 创建页

创建页是项目方的主要入口，负责接收：

- 基础代币信息
- 预售价格
- 软硬顶
- 单笔和单钱包限制
- 截止时间
- Logo 与社交信息
- 模板选择

## 模板页

模板页展示平台的内置模板与已审核通过的开发者模板，帮助项目方区分平台标准模板与扩展模板。

## 开发者页

开发者页是模板接入入口。它不是“上传任意合约就能上架”，而是提交符合平台接口规范的 deployer 与说明材料，等待后台审核。

## 项目页

项目页展示募资状态、配置信息、参与入口和项目基本资料，是预售期间的主要交互页。

## 代币页

代币页承接 finalize 之后的公开交易阶段，聚合：

- 市场信息
- 流动性信息
- 最近交易
- 买卖入口

## 管理后台

后台负责：

- 模板审核
- 项目隐藏
- 手动验证补单
- 管理端统计

## 面向的人群

### 项目方

项目方需要的是标准化流程、统一 UI 和明确状态，而不是自己管理多个脚本与多个合约入口。

### 机制开发者

机制开发者关注的是模板如何进入平台、需要满足哪些接口、审核通过后如何变成正式模板、平台如何继续托管发射流程。

### 参与者与交易用户

参与者更关注募资进度、项目资料、交易是否开放、流动性是否建立、最近交易是否可见。

### 集成方

钱包、机器人、终端和索引服务更关心：

- 稳定的合约地址
- 稳定的状态读取方式
- 项目和代币之间的映射关系
- 可消费的 API 和事件数据
