# 模板生命周期

本页说明一个开发者模板从提交到变成平台正式模板，会经历哪些阶段。

## 1. 模板开发

开发者先实现自己的 deployer 与 token core，并确保它满足平台要求：

- 接口完整
- 参数可解码
- 状态可验证
- 不绕平台资金和 finalize 路径

## 2. 提交审核

模板通过开发者入口提交到后台待审核列表。此时模板还不是公开模板，只是进入审核流程。

## 3. 后台审核

管理员会审查：

- 机制是否清晰
- 是否满足平台接口
- 是否存在明显后门或越权逻辑
- 参数结构是否合理

审核不是文案通过，而是是否允许模板进入平台正式体系。

## 4. FactoryAdmin 注册

审核通过后，管理员通过 `FactoryAdmin` 把模板注册进平台。模板在链上获得：

- template id
- deployer 绑定
- 启用状态
- 策略限制信息

## 5. 前台模板展示

注册完成后，前端会从链上读取模板列表，模板进入公开模板区，可供项目方选择。

## 6. 项目实际使用

项目方选择模板后，创建页会根据模板的参数结构要求生成对应输入，并把参数编码到创建交易里。

## 7. 平台发射

模板在实际创建项目时，不是独立于平台运行，而是进入平台发射主路径：

- 模板路由
- 项目创建
- 募资
- finalize
- 验证

## 8. 模板运营期

模板进入平台后，不等于永远不可管理。平台可以：

- 保持模板启用
- 暂停模板
- 调整审核策略

这保证模板体系不是一旦上架就无法治理。
