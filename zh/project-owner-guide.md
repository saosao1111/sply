# 项目方指南

本页从项目方视角说明如何在 SPLY 上发起项目，以及在创建前应该理解哪些关键参数。

## 创建前应该先确认什么

项目方至少要先明确以下问题：

- 你要使用哪个模板
- 总量与预售价格如何匹配
- 软顶和硬顶如何设置
- 单笔与单钱包限制如何设置
- 截止时间怎么定
- 你希望展示哪些项目资料与社交链接

如果模板本身还带机制参数，那么模板参数也应该在创建前先确认，而不是在链上临时试错。

## 创建页的核心字段

## 基础信息

- Token Name
- Token Symbol
- Total Supply
- Description
- Logo
- Social Links

这些字段会影响项目页、代币页和对外展示体验。

## 募资参数

- Presale Price
- Hard Cap
- Soft Cap
- Max Per Tx
- Max Per Wallet
- End Time

这些字段决定的是募资行为和募资边界，不是代币机制本身。

## 模板参数

如果选择内置模板或开发者模板，创建页会额外显示模板参数输入区。模板参数不是通用参数，而是某个模板 deployer 的专用配置。

## 创建之后会发生什么

项目创建成功后，平台会生成对应项目对象，并在项目页展示：

- 当前募资进度
- 软硬顶与参与限制
- 项目资料
- 参与入口

在募资阶段，项目方最重要的是关注募资是否达到目标，而不是自己再手工处理流动性或市场初始化。

## finalize 之后项目方需要知道什么

一旦项目进入 finalize，平台会自动推动项目进入标准市场状态。项目方需要理解的重点是：

- LP 会在 finalize 阶段建立
- 交易会在 finalize 阶段开启
- 关键权限会在 finalize 阶段收口
- 自动验证会在 finalize 后进入队列

也就是说，项目方不需要自己再处理一条完全独立的开盘流程。

## 项目方的最佳实践

- 在创建前先确定好模板与模板参数
- 保持总量、价格、软硬顶之间的数学关系清晰
- 在项目说明中把机制讲清楚
- 把 Logo 和社交链接准备好，避免影响项目页可信度
- 把测试项目和正式项目分开管理
